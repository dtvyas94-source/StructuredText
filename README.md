# StructuredText

Tutorial to learn Structured Text from zero


Structured Text Learning Journey (TwinCAT 3)

A repository documenting a step-by-step learning path for PLC programming using Structured Text (IEC 61131-3) in Beckhoff TwinCAT 3, starting from absolute beginner concepts to practical automation logic.

Overview
This repository contains code snippets, exercises, and mini-projects developed while learning industrial programming fundamentals.

Prerequisites
Beckhoff TwinCAT 3 (XAE Shell or Visual Studio integration)

Basic familiarity with computer logic (variables, conditions)

Roadmap:
Level 1: Variables, Data Types, and Basic Arithmetic

Level 2: Conditional Statements (IF, CASE)

Level 3: Iterative Loops (FOR, WHILE)

Level 4: Functions and Function Blocks (POUs)

Level 5: State Machines and Practical Projects
